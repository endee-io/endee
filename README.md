# Endee

Endee.io – A high-performance vector database, designed to handle up to 1B
vectors on a single node, delivering significant performance gains through
optimized indexing and execution.

Endee is built on proprietary algorithms. It is available in the **cloud** and
under the **Endee Enterprise license**.

This repository does not contain source code.

## Endee Cloud

Endee is available as a fully managed cloud service.

👉 **[Get started with Endee Cloud](https://endee.io)**

## Endee Enterprise

Endee is available as **Endee Enterprise**. It is actively developed and
fully supported.

**A free 30-day evaluation license is available for testing.**

👉 **[Get started with Endee Enterprise](https://docs.endee.io/v2/quick-start/enterprise)**

The documentation covers:
- Installation and setup
- How to request your 30-day evaluation license
- Licensing options for production use
