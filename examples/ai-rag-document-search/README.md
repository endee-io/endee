# AI PDF Chat with RAG using Endee Vector Database

This project implements an AI-powered document question answering system.

Users upload PDF documents and ask questions. The system retrieves relevant
document chunks using vector similarity search and generates answers using
Retrieval Augmented Generation (RAG).

## Tech Stack

Frontend: React  
Backend: FastAPI  
Vector Database: Endee  
Embeddings: Sentence Transformers  
LLM: OpenAI

## Features

- PDF Upload
- Semantic Search
- Vector Embeddings
- RAG Question Answering
- Simple AI Chat Interface
