# Employee Memory AI

AI-powered backend to store and search employee activities using vector embeddings.

## Features

- Add employee memory
- Semantic search using AI
- Department filtering

## Tech Stack

- FastAPI
- FAISS
- Sentence Transformers

## Run Locally

```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
Run the bat file "run_app.bat"
