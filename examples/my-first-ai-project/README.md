# AI Semantic Search Project using Endee

## Description
This project demonstrates semantic search using embeddings.

## Features
- Converts text into embeddings
- Accepts user query
- Finds most relevant answer

## How to Run
1. Install dependencies:
   pip install sentence-transformers

2. Run:
   python main.py
